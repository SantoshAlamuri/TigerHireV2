# Architecture Decision Records (ADRs)

One file per significant decision. Use this template for new ADRs.

## Template

```markdown
# ADR NNN: Short title

## Status

Proposed | Accepted | Deprecated

## Context

What is the issue or opportunity? What constraints exist?

## Decision

What did we decide? Be specific.

## Consequences

What are the positive and negative outcomes? What do we need to do next?
```
