# Withdrawing an application

Candidates can withdraw an application only while it is still in **Applied** (pending review) status.

## Steps

1. Go to **My Applications** (from your candidate dashboard or sidebar).
2. Find the application you want to withdraw. The status badge will show **Applied** for applications that can be withdrawn.
3. Click **Withdraw** next to that application.
4. In the confirmation dialog, review the job title and note that the recruiter will be notified.
5. Click **Withdraw** to confirm, or **Cancel** to keep the application.

After you withdraw:

- The application status changes to **Withdrawn** and the recruiter is notified (in-app and by email).
- You can still see it in **My Applications** by using the **Withdrawn** filter.
- Withdrawal cannot be undone; if you change your mind, you would need to apply again (if the job still accepts applications).

## Filters

On **My Applications** you can filter by status, including **Withdrawn**, to see only withdrawn applications.

## Recruiter side

Recruiters see withdrawn applications in their pipeline and receive an in-app notification and an email when a candidate withdraws, so they can keep their pipeline up to date.
