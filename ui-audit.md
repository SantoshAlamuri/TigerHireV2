# UI Density & Readability Audit

**Date:** 2026-07-15 · **Scope:** candidate list, candidate detail/FitScore, scheduling (calendar), dashboards (recruiter + company) · **Method:** Playwright full-page captures at 1440px and 390px on local dev (Sydney preview data, finstack demo org) + Tailwind-level code pass on the same routes.

Screenshots: `/private/tmp/claude-501/…/scratchpad/shots/full-*.png` (desktop + mobile per screen).

**The two systemic problems** (explain ~80% of findings):

1. **Type/contrast floor is too low.** Titles get 14px+; nearly all _information_ — labels, meta rows, KPI explanations, caveats, timestamps — is 9–12px at 40–65% white. The recurring `text-[10px] uppercase text-white/45` micro-label appears on every screen. `globals.css` already defines `.text-label` (11px) and `.text-caption` (10px) utilities for exactly this (audit F-15), but almost nothing uses them — components hardcode `text-[10px]`/`text-[11px]` and drift. Note `.text-body` sets **only line-height**, so `text-body text-xs` looks sanctioned but renders 12px.
2. **CTA scale inversion + duplication.** Primary actions are `text-xs py-1` pills while read-only numerals are `text-2xl font-extrabold`; and on both dashboards the same three metrics (pending feedback / tomorrow interviews / applied inbox) render 3–4 times each.

Severity: **P0** = broken/unusable · **P1** = measurable strain on a core loop · **P2** = polish. Everything below fits ~2 days: Day 1 = class sweeps (§1–§4 type/contrast items), Day 2 = mobile fixes + dashboard dedup.

## Cross-cutting fix (do first, ~half day, covers most P1 type/contrast items)

1. **Adopt the existing utilities**: replace hardcoded `text-[10px]`/`text-[11px]` with `.text-label`/`.text-caption` (globals.css:207–215) so the small end stops drifting. ~15 sites carry section structure; one shared eyebrow pattern (`text-xs font-semibold uppercase tracking-wider text-white/60`) fixes them all.
2. **Alpha floor**: any text conveying information ≥ `text-white/60` (or `--text-muted`); reserve `/45`–`/55` and `--text-subtle` for genuinely decorative text.
3. **Size floor**: content the user reads (meta rows, answers, evidence, caveats, form controls, CTAs) ≥ `text-sm`; 12px only for badges/chips; nothing below 11px anywhere.

## Out of scope for the 2 days (noted for the backlog)

## Environment/process notes from the audit (not UI issues)

- **Root `.env.local` mixes projects**: `SUPABASE_INTERNAL_URL` points at **prod Mumbai** (`qzhhhsvtyqyixpcdfhng`) while URL/keys are Sydney preview — the admin client sends Sydney's service key to prod, gets "Invalid API key", and **every rate-limited API fails closed with a user-facing "Too many requests"** (misleading error for a config problem). I commented the var out in the worktree copy only; fix the root file the same way for local dev.
- `/company/interviews` redirects to `/calendar` for non-interviewer roles (plan-document nav) — the "scheduling flow" audited is the calendar.
- Screenshot tooling gotcha: the app scrolls in an inner container, so Playwright `fullPage` captures only the viewport — use a tall viewport instead.
