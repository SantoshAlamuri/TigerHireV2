Role Architecture 2.1 Overview TigerHire uses a single login page that routes every user to their relevant experience based on their role. There are 6 distinct roles across the platform. The system determines what to show after authentication.  Post-Login Routing Logic 1. User lands on tigerhire.in/login  →  enters email + password (or Google OAuth / magic link) 2. Supabase Auth verifies credentials  →  JWT issued with user's role claim embedded 3. Next.js middleware reads role claim from JWT on every request:       role === 'super_admin'    →  /admin/dashboard       role === 'company_admin'  →  /company/dashboard       role === 'recruiter'      →  /recruit/dashboard       role === 'agency'         →  /agency/dashboard       role === 'candidate_pro'  →  /candidate/dashboard       role === 'candidate_free' →  /candidate/dashboard  (with locked sections shown, not hidden) 4. Navigation items rendered dynamically based on role — candidates never see recruiter features 5. First login: role selection screen (I am a... Company / Agency / Job Seeker)  →  sets role permanently 6. Role upgrade (Free → Pro): in-app prompt  →  Stripe checkout  →  role updated on payment success  2.4 Registration Flow per Role Role Registration Path Verification Required First Screen After Login Company Admin tigerhire.in/register  → 'I'm hiring'  → company name + work email → email verify Work email domain verified (no personal Gmail) Dashboard: FitScore shortlist for open roles (or 'Post your first JD' if new) Recruiter Invited by Company Admin via email link → accepts invite → sets password Invite token verification Dashboard: JD list with FitScore counts Agency / RPO tigerhire.in/register → 'I'm an agency' → agency name + contact → manual approval by admin Manual admin approval (prevents abuse) Agency dashboard: client list + active JDs Candidate (Free) Detected profile: 'Claim your profile' email/WhatsApp → verify email/phone → profile confirmed Email or WhatsApp OTP Profile page: match count, top 3 JDs, upgrade prompt Candidate (Pro) Same as Free → Stripe payment → instant role upgrade Payment confirmation Full dashboard: FitScore breakdown, all JDs, AI tools Super Admin Seeded by developer at database level — no public registration path N/A — internal only Full admin panel: all data, agent logs, billing overview 3.
